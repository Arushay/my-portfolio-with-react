# Arosha Ayman — Portfolio

A clean, modern personal portfolio built with **React**, **Tailwind CSS**, and **Vite**. It showcases my full-stack projects and provides a way to get in touch.

🔗 **Live site:** [arushay-portfolio.vercel.app](https://arushay-portfolio.vercel.app)

---

## ✨ Features

- Responsive layout (mobile and desktop)
- Dark theme with blue accent
- Sections: Hero, Projects, About, Contact
- Project cards with tech stack tags and GitHub links
- Auto-deployed via Vercel on every push to `main`

---

## 🛠️ Tech Stack

- **React** — UI components
- **Tailwind CSS** — styling
- **Vite** — build tool and dev server
- **React Icons** — social and contact icons
- **Vercel** — hosting and continuous deployment

---
## 🚀 Run Locally

Clone the repo and install dependencies:

```bash
git clone https://github.com/Arushay/my-portfolio-with-react.git
cd my-portfolio-with-react
npm install
```

Start the dev server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
